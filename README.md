# MVP Imóveis & Repasses

Protótipo local em Next.js para demonstrar:

- tela de login demo;
- cadastro de proprietários;
- baixa de cobranças como pagas;
- saldo por proprietário;
- fechamento mensal e lote de repasse.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra: http://localhost:3000

O login é apenas demonstrativo: qualquer e-mail e senha entram.
